## 本分支新增功能

> 本仓库 fork 自 [WangJie0822/Cashbook](https://github.com/WangJie0822/Cashbook)（Apache-2.0），在上游基础上主要新增「**半自动记账**」与「**支付宝账单导入**」，并优化了记账页交互与性能。以下功能自 `v1.3.3_26100716` 起可用，完整变更见 [CHANGELOG.md](CHANGELOG.md)。

### 半自动记账

思路：**监听支付类 App 的通知 → 命中你配置的匹配文本 → 弹出记账提醒 → 点击后打开记账页并预填，确认后保存**。全程不联网、不自动写账，是否记账由你决定。

#### 开启步骤

1. 进入 **设置 → 半自动记账**，打开开关（Android 13+ 会同时请求通知权限，用于展示记账提醒）；
2. 点击 **通知使用权** 项，在系统「通知使用权」列表中授权本应用；开关已打开但未授权时，设置页会红色提示 **未开启通知使用权，将无法监听支付通知**；
3. 打开 **设置 → 半自动记账 → 匹配文本 → 设置匹配文本**，按你手机里支付通知的真实文案添加规则（可加多条，微信 / 支付宝 / 银行各一条）。

#### 匹配文本写法

用 `*` 标记金额位置：**第一个 `*` 之前是前缀**（只要在通知文本中出现即命中，不要求开头），其后的 `*` 等价于「任意文本」。

| 配置的匹配文本 | 可命中的通知文案示例 | 取到的金额 |
| --- | --- | --- |
| `微信支付 * 元` | 微信支付 19.99 元 | 19.99 |
| `你有一笔*元的支出` | 支付宝 你有一笔19.99元的支出 | 19.99 |
| `消费*人民币` | 消费 ￥188.00 人民币，余额… | 188.00 |

匹配范围是**通知标题 + 正文**（银行 App 常把银行名放标题、金额放正文），并做归一化：

- 空白（全角空格、换行、连续空格）折叠为单个空格；
- 全角数字与全角小数点自动转半角；
- 金额支持千分位（`1,234.56`）、货币符号与前后文字（`19.99元整`、`¥1,234.56`）；
- 支持负号（退款等场景）；单笔超过 1000 亿元视为无效，避免解析溢出。

配置多条时，**优先采用第一条能解析出金额的规则**；若命中的规则都解析不出金额，仍会提醒记账，只是不预填金额。

#### 命中之后

1. 收到通知 **「来自 `<来源应用名>` 的记账提醒」**：`金额：19.99，点击记一笔`（未解析出金额时为 `点击记一笔`）；短时间内多笔命中**各自保留一条提醒**（最多同时 4 条，超出后回收最早一条），不会互相覆盖；
2. 点击通知 → 打开 App 进入 **添加记录** 页并预填：**金额**（通知中匹配到的金额）、**备注**（来源应用名，如「支付宝」）、**分类**（当前账本上一次记账使用的类型）；
3. 核对无误后保存即可；同一条通知重复点击不会覆盖你已经改过的内容（预填只生效一次）。

#### 使用建议与说明

- 匹配文本要与通知文案同源（含空格），可先用宽松规则（如 `支付 * 元`）试跑再逐步收紧；
- 需保持 **通知使用权** 授权有效，系统清理授权、换机或重装后需重新勾选；
- 开关关闭、未授权、匹配文本为空或未命中时不会产生任何提醒，不做多余打扰；
- 同一条支付通知被更新（如「处理中」→「支付成功」）、或同一应用在 10 秒内重复投递同额通知，只会保留一条提醒，不重复打扰；
- 通知内容仅在设备本地参与匹配与金额提取，**不上传、不联网、不写入数据库或文件**；正式版默认不输出日志，仅当你在「关于我们 - 日志状态」中主动开启日志（或使用调试版本）时，比对文本会输出到不落盘的系统日志（Logcat）；账本数据与上游版本一致，完全本地存储。

### 支付宝账单导入

- 入口：**设置 → 备份与恢复 → 导入账单 → 从支付宝导入**，选择支付宝导出的 `.xlsx` 账单（「从微信导入」沿用上游能力）；
- 只保留「交易成功」的交易，解析时按表头动态定位列，兼容官方导出格式变化；
- **分类自动映射**：优先按名称匹配你的**二级分类**，其次匹配**一级分类**，都没有时按账单的「交易分类」自动创建一级分类；账单中的「退款」统一归入内置「退款」分类；
- **自动去重**：按「支付宝单号」精确去重（单号存于备注，形如 `[支付宝单号:xxx]`），同天同额记录标记为「疑似重复」且默认不勾选；
- 导入前可逐条预览 / 勾选，确认后提示 `成功导入 N 条记录，跳过 M 条`。

### 记账页与统计优化

- **数字键盘常驻底部**：金额 / 手续费 / 优惠目标一键切换，输入法弹起时自动收起，减少滚动与点击；
- **保存入口移至标题栏右侧**，「保存」「再记」统一由常驻键盘触发，收敛到同一保存入口；
- 备注栏上移、类型区可滚动（最小高度 160dp），类型多时不再挤压布局；
- **性能**：类型区懒加载 + 类型查询去除 N+1，编辑记账页冷流去重、首屏关键路径瘦身，进入记账页更快；
- **统计图表**：按天补齐零点、支出统一取正、横轴仅显示日期且不再重叠；
- **数据修复**：编辑二级分类不再丢失父分类；启动时自动把「孤儿二级分类」提升为一级分类（幂等，仅影响异常数据）。

## 项目说明
一个自用记账本APP，从18年开始，就一直在使用**网易有钱**记账，考虑到个人隐私以及安全性问题，一直都是离线使用，21年年初突然听说**网易有钱**要停止运营了，看到相关信息说是停止运营前可以导出数据转到其他平台使用，因此连上网络准备导出，就这一步操作，让我记录了有三年多的数据全部丢失。之后终止了一段时间的记账，在这期间感觉到非常的没有安全感，感觉一下子对自己的资产没有了感知，这个月花了多少，收入多少，结余多少完全没有了概念，因此觉得记账还是必不可少，也尝试了其它不少记账APP，但都有或多或少的问题，要不就是功能不满足要求，要不就是要收费，而且还是不想把个人记账相关的信息暴露给三方的平台，最终还是决定自己写一个来使用。

因为个人开发，所以没有好的**UI**方面的想法，因此在界面设计以及功能方面借鉴了不少其它APP：

* 网易有钱
* 薄荷记账
* 钱迹
* Expenses

## 使用说明
1. 你可以从本分支的发行版本中下载最新的安装包：[Github Releases](https://github.com/ImGonnaDans/Cashbook_auto/releases)（提供 online / offline 两个渠道的 APK；上游原版见 [WangJie0822/Cashbook](https://github.com/WangJie0822/Cashbook/releases)）；

2. 你也可以将项目下载到本地运行，运行项目前请在项目 /gradle 路径下按如下格式添加文件 signing.versions.toml

```toml
[versions]
# 密钥别名
keyAlias = ""
# 别名密码
keyPassword = ""
# 密钥文件路径
storeFile = ""
# 密钥密码
storePassword = ""
```
